## Изменённые маршруты и redirects

Новых маршрутов и redirects нет. Добавлены query-параметры: `/?w=…`, `/deals?block=…` (раньше читался только при входе), `/deals/:id?tab=…` (раньше — только при входе, теперь всегда в адресе), `/summary?kind=…` (то же), `/legal?…&client=<id>`.
Старые адреса проверены: `/team`, `/access`, `/admin`, `/clients`, `/factories`, `/counterparties`, `/parts/setup`, `/legal?tab=own`, `?s=…` из уведомлений и ежедневной сводки.

Поведение, которое изменилось намеренно:
- `/settings` без `?s=` открывает категории (раньше — первую доступную секцию, обычно «Ставки и нормативы»).
- Переключение вкладок в Юр. блоке, Контрагентах, Настройках, Снабжении, Каталоге, Сводке, реестре и карточке сделки — новая запись истории: «Назад» возвращает прежнюю вкладку (раньше заменяло адрес).

## Не сделано / ограничения

- Рабочее место перестроено полностью; в остальных разделах этап 1 — путь, адрес уровня и история. Отдельный «обзор» первого уровня есть только у Настроек (у Финансов он уже был). Обзоры для Юр. блока, Каталога, Снабжения и карточки сделки («Обзор» как отдельный уровень до вкладок), режим «Все колонки» в реестрах — следующий этап.
- Матрица покрывает рабочее место, карточку сделки и навигацию разделов; поэлементная матрица по каждой таблице и форме Финансов, Юр. блока, Снабжения не составлялась — эти экраны внутри не менялись.
- Не проверено: production-сборка через nginx, реальный вход по паролю (проверялось через `X-Dev-User` стенда), step-up и TOTP-сценарии, скринридеры.
- После D-097 большинство блоков по умолчанию скрыто, поэтому у входов «Сделки»/«Задачи» счётчики появляются только для включённых блоков; при скрытом блоке «Быстрые действия» меню в шапке не показывается (как и сам блок в `main`).
- Существующее, не связанное с изменениями: на ширине 390 px меню по роли (`.nav-more`, D-097) даёт горизонтальную прокрутку страницы (≈520 px) на всех страницах; прямой адрес `/board` у ролей без доступа выдаёт 403 и необработанную ошибку в консоли.
