## Переключатель «Новый вид / Прежний вид»

Для сравнения вариантов на одном стенде. Стоит в шапке рабочего места и в Настройках (`UiModeSwitch`, `useUiMode` в `Levels.tsx`).

- Выбор хранится в браузере (`localStorage`, ключ `gsho.uiMode`: `new` — по умолчанию, `classic`); на сервере и в профиле сотрудника не сохраняется, у каждого браузера свой.
- «Прежний вид» меняет два экрана: рабочее место показывает сразу все включённые блоки (как в `main`, без входов, пути и строки направлений; `?w=…` игнорируется), `/settings` без `?s=` открывает первую секцию.
- В обоих видах одинаково: путь в остальных разделах, вкладки в адресе, строка «Связано» в сделке, исправление «Сводки».
- Когда вариант выбран, переключатель убирается: удалить `UiModeSwitch`/`useUiMode` и ветки `classic` в `WorkplacePage.tsx` и `SettingsHub.tsx`.

Новых маршрутов и redirects нет. Добавлены query-параметры: `/?w=…`, `/deals?block=…` (раньше читался только при входе), `/deals/:id?tab=…` (раньше — только при входе, теперь всегда в адресе), `/summary?kind=…` (то же), `/legal?…&client=<id>`.

## Не сделано / ограничения

- Не проверено: вход по паролю и код из приложения на этапе 2 (локально — тестовый переключатель учётных записей), step-up, read-only состояния поэлементно, скринридеры, production-сборка через nginx.
- «Все колонки» сделано только для реестра сделок; реестры клиентов, договоров, склада показывают полный набор, как раньше.
- В реестре сделок с основными колонками на ширине 1440 px остаётся небольшая горизонтальная прокрутка таблицы (≈50 px; с полным набором — ≈360 px).
- Обзор Каталога — входы и поиск без счётчиков.
- Выбор вида и набора колонок хранится в браузере, не в профиле сотрудника.
- После D-097 большинство блоков рабочего места по умолчанию скрыто, поэтому у входов «Сделки»/«Задачи» счётчики появляются только для включённых блоков.
- Существующее, не связанное с изменениями: на ширине 390 px меню по роли (`.nav-more`, D-097) даёт горизонтальную прокрутку страницы; прямой адрес `/board` у ролей без доступа выдаёт 403 и необработанную ошибку в консоли.
