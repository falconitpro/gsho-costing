# Отчёт о правке 4 — прогноз по утверждённому расчёту и замещение договором (этап 2)

- Дата: 10.11.2026. Ветка `feat/finance-option-b-4` от `main` `c126b2b` (PR #119 слит). Решения D-126, D-127. Статус: **завершён**.

## Сверка с кодом

- Утверждённая версия — `Deal.approved_version_id`; результат — `calc_result.variants[вариант][сценарий]`.
- График клиента — `payment_dates` (сумма в RUB), графики заводу — `positions[].factory_payment_dates` (сумма и валюта завода). Проверено на реальной версии в тестовой БД.
- Все смены статуса сделки проходят через `deal_service.apply_transition` — туда подключена пересборка прогноза.

## Что сделано

- Прогноз строится по выигранной сделке: базовый сценарий, выигравший вариант; клиент — «нам платят» (RUB), заводы — «мы платим» (валюта завода), без юридического срока.
- Подписанный договор замещает прогноз своей стороны: при совпадении номера строки — ссылкой на строку договора, иначе — исключением с причиной. Двойного итога нет (проверено тестом по итогам).
- Новая утверждённая версия переводит строки прежней в историю; закрытая сделка — прогноз вне итогов.
- Прогнозная строка с разнесёнными деньгами при замещении уходит на сверку.
- Повторная полная сборка ничего не меняет (тест).
- UI: бейдж «прогноз», фильтр «прогноз по расчёту».
