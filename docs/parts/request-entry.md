# Сделки: ГШО / Запасные части, заведение заявки, остатки по складам

## Что сделано

- **Сделки** — слева крупные вкладки «ГШО» и «Запасные части» со счётчиками, плюс «все сделки вместе». Кнопка создания меняется по вкладке: «Новая сделка ГШО» или «Новая заявка на запчасти».
- **Новая заявка на запчасти** — мастер из трёх шагов:
  1. клиент и машина из парка клиента, контакт, канал, срочность, гарантия;
  2. позиции, добавляются тремя способами:
     - «Из каталога» — поиск по номеру или наименованию;
     - «Из файла заказа клиента» — xlsx/xlsm/csv;
     - «Вставить из письма / Excel».

     Одинаковые позиции объединяются. По каждой строке видно, нашлась ли она в каталоге, и сразу видно наличие на всех складах;
  3. «Создать заявку (N строк)».
- **Удаление ошибочной заявки** — кнопка «Удалить заявку» в карточке.
- **Поставщики** — выпадающий список заведённых поставщиков со строкой «＋ Добавить нового поставщика…» (форма прямо в заявке). То же в подборе завода ГШО.
- **Склад → Остатки по складам**:
  - карточки «Все склады» и по каждому складу: свободно, позиций, всего, резерв, в пути, ниже минимума, стоимость по закупке (только при праве на себестоимость);
  - фильтры: поиск, группа, сортировка, «только с остатком», «ниже минимума»;
  - таблица по складам;
  - выгрузка в Excel.

## Решения

| № | Решение |
|---|---|
| D-171 | **Файл заказа клиента.** xlsx/xlsm (первый непустой лист) и csv/txt (utf-8 или cp1251; разделитель `;`, `,` или Tab). Шапка ищется в первых 20 строках по словам «артикул/каталожный номер», «наименование», «кол-во», «ед.». Без шапки: первая колонка — номер, последняя числовая — количество. Строки «итого/всего» пропускаются. Если количество не указано, ставится 1, и строка показывается в списке «проверьте». .xls и PDF не принимаются: просим сохранить файл как xlsx. |
| D-172 | **Строки из каталога.** Строка с `part_id` берёт номер, наименование и ед. изм. из карточки (`match_kind = manual`). Свободный текст по-прежнему сопоставляется автоматически. |
| D-173 | **Удаление заявки.** Удалить может менеджер заявки, КД или ГД. Удаление запрещено (409), если по заявке есть КП, строки ушли дальше подбора, или есть заказ поставщику, отгрузка либо рекламация. Связи с запросами поставщикам снимаются; запросы, оставшиеся без строк, закрываются. Перед удалением в журнал пишется снимок заявки. |
| D-174 | **Наличие в строках.** По каждой позиции показывается «есть / есть N из M / нет на складах» и разбивка «Склад: свободно (в резерве R)». Это работает и в мастере (`POST /api/parts/requests/preview-lines`), и в карточке заявки (`lines[].warehouses`). |
| D-175 | **Остатки по складам.** `GET /api/parts/stock/balances` (фильтры `q`, `warehouse_id`, `group`, `only_positive`, `below_min`, `sort`) и `/balances/xlsx` (листы «Остатки» и «Склады»). Стоимость считается по цене закупки и курсу ЦБ и видна только при праве `cost`. |

## Остатки из МойСклад

Остатки — это снимок на дату импорта; живой синхронизации нет. Чтобы обновить: «Каталог → Импорт → Остатки», выгрузка из МойСклад.
