## 2. Объём

### Реализовано

- **Кнопка «Помощник» в шапке и панель справа.** На телефоне панель на весь экран. В панели:
  - пояснение при первом открытии: что видит помощник, что внешняя модель не используется, срок хранения, запрет вводить пароли;
  - режимы «Вопросы по CRM», «Справка» и «Общий вопрос» (выключен, сказано честно);
  - быстрые вопросы;
  - источники под ответом с переходом;
  - «Новый диалог», «История», «Удалить диалог» с подтверждением.
  - Enter отправляет, Shift+Enter — новая строка. Esc закрывает, черновик сохраняется. Неотправленный из-за ошибки вопрос возвращается в поле.
- **Инструменты:**
  - сделка по номеру и поиск сделок;
  - история цен заводов;
  - задолженность по направлению и контрагенту;
  - мои задачи;
  - «что требует моего решения» (= «Ваши приоритеты»);
  - справка из 14 статей.
- **API:** `/api/assistant/status`, conversations (список, создание, чтение, удаление), messages, feedback, admin/metrics.
- **Лимиты, повтор без двойного списания, очистка по сроку хранения.** Включение модели позже — одной настройкой, с проверкой ответа (D-055).

### Не вошло

- Внешняя модель (решение владельца). Код для неё есть и проверен подставным адаптером. Включение: `ASSISTANT_PROVIDER=yandexgpt`, `ASSISTANT_CONTEXT_POLICY=allow_minimized` в `backend/.env`.
- Кнопки «стоп» и «повторить»: ответ мгновенный и детерминированный, повтор — та же отправка с тем же ключом.

`tests/test_assistant.py`:
- AI-01: чужой диалог и отзыв — 404, в том числе для админа и ЗГД; без `assistant_use` — 403;
- AI-02: сделка чужому — «не найдена», без утечки; цены без права — «недоступна»; задачи — свои и по замещению;
- AI-03: SQL, путь к файлу, чужой пользователь, «закрой сделку» — без последствий, только инструменты из списка;
- AI-04: источники только из инструментов;
- AI-05: долг совпадает с `/api/finance/debt`, RUB и CNY отдельно; без права — без сумм; неоднозначный вопрос — уточнение; цены в USD и CNY не усредняются;
- AI-06: модель выключена — справка и CRM работают, общий режим честно выключен; подставная модель — уходит только текст без ссылок, выдуманные числа, ссылки и таймаут дают исходный ответ;
- AI-07: 10 параллельных запросов при лимите 5 — ровно 4 проходят (1 уже потрачен), повтор не списан, минутный лимит;
- AI-08: удаление и срок хранения стирают содержимое, технический след без содержимого остаётся;
- статистика без текстов;
- «что требует решения» совпадает со сводкой.

Браузерный сценарий:
1. пояснение при первом открытии;
2. «Что требует моего решения?» — дела из сводки, переход по источнику в сделку;
3. справка «Как сменить пароль?»;
4. общий режим — «отключён»;
5. «сколько должны?» — уточнение;
6. Esc — черновик сохранён;
7. история и удаление диалога.
