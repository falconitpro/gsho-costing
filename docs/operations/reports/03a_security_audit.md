## 2. Объём

### Реализовано

- **Журнал скачиваний и выгрузок** (D-046) одной прослойкой на все маршруты API: успех, отказ, кто, сессия, сделка, объект, формат, размер, число строк, фильтры. Имени файла, пути хранения, ссылки, содержимого и текста поиска в журнале нет. Без записи в журнал закрытый файл не выдаётся (503).
- **Предупреждения безопасности** (D-047): 9 правил версии `2026-11-v1`, дедупликация по правилу и сотруднику, счётчик повторов, уведомление «в системе» держателям `security_audit`. «Взять в работу» и «Закрыть» — с комментарием; критическое закрывается с подтверждением.
- **События изменения прав**: уровень роли, исключение (задано/удалено), роли сотрудника. Сброс кода, отключение, временный пароль и просрочка пересмотра прав тоже дают предупреждение.
- **Подтверждение при повышении прав безопасности** и ролей ЗГД/администратор (D-048).
- **S3**: ссылка на 5 минут после проверки прав, «скачать» по умолчанию, в базе — только адрес системы (D-048).
- **Экран** «Настройки → Журнал и предупреждения» (право `security_audit`): счётчики открытых по важности, фильтры (статус, важность, правило, даты), карточка с деталями и связанными событиями, действия; журнал событий с фильтрами (тип, результат, даты, сотрудник), постранично.

### Не вошло (3б)

- ClamAV, карантин, статус проверки файла, `legacy_unscanned` (FILE-01…05, 07, 08).
- `APP_ENV=recovery` / `DATA_CLASSIFICATION` и отказ старта при опасных сочетаниях (`04` §10).
