## 2. Объём

### Реализовано

- **Кампания** (`access_review_campaigns`): название, период, срок, круг (все активные или выбранные роли). При создании фиксируется снимок каждого сотрудника: роли, эффективные права, права сверх роли, особые права (безопасность, доступ, журнал, копии, финансы), исключения с их сроками («бессрочные/долгие» — без срока или дольше 90 дней), область наблюдения, замещения, код из приложения, последний вход и дни без входа. Паролей, секретов кода и токенов в снимке нет.
- **Решения** по каждому сотруднику: «Оставить»; «Изменено» — только при реальной разнице прав со снимком, разница сохраняется, комментарий обязателен; «Отключить» — через единую операцию отключения (D-038); «Пропуск по решению владельца» — с причиной; «Пересмотреть» — вернуть в нерешённые.
- **Второй проверяющий**: свои повышенные права проверяющий не подтверждает (сервер отвечает 409, интерфейс показывает «нужен другой проверяющий»).
- **Ход проверки**: процент, разбивка решений, просрочка, число сотрудников с бессрочными исключениями и с правами «нужен другой проверяющий». Завершение — только когда решены все, с итогом. Отмена — с причиной.
- **Напоминания** «в системе» администраторам безопасности за 14, 7 и 1 день и при просрочке, по одному разу (ежедневный цикл). Переход из колокольчика — в раздел.
- **Экран** «Настройки → Пересмотр прав» (право `security_admin`): список проверок, создание (по умолчанию текущий квартал, срок +14 дней), карточка сотрудника с правами, исключениями и «изменилось с начала проверки».

### Не вошло

- Тревога безопасности о просрочке — с журналом тревог (этап 3); пока только уведомление.
- Назначение конкретных проверяющих на кампанию: решения принимает любой администратор безопасности, кто и когда — фиксируется.
