Демо-страница интерфейса без сервера: откройте `index.html` в браузере.
Данные тестовой сделки D-2026-0042 посчитаны реальным расчётным ядром (`backend/app/calc`).
Переключатель роли в шапке показывает, что видит каждая роль. Ссылки во вкладке «Версии и файлы» ведут в `../samples/`.
Полноценный стенд с базой и API: `docker compose up --build` (см. README.md в корне).
