# BERGHAUS — логотип в векторе (26.11.2026)

Перерисовано по исходнику `logo-main.png` из проекта CRM. Прямые элементы знака (H, крыша, треугольники) построены
как точные многоугольники: углы 45°, общая базовая линия, ось симметрии крыши. Буква B и надпись BERGHAUS обведены
кривыми Безье по исходнику. Отклонение от исходника — только сглаживание краёв, в среднем меньше 1 % яркости на пиксель.

## Цвета
- Красный BERGHAUS: **#FF3131** (RGB 255 49 49).
- Чёрный: #000000. На тёмном фоне чёрные элементы становятся белыми (#FFFFFF), красный не меняется.

## Варианты (svg/, pdf/, eps/, png/)
| Файл | Где использовать |
|---|---|
| berghaus-logo-color | полный логотип на светлом фоне (основной) |
| berghaus-logo-on-dark | полный логотип на тёмном фоне |
| berghaus-logo-black / -white | одноцветная печать, гравировка, тиснение |
| berghaus-mark-color / -on-dark / -black / -white | знак BHA без надписи: аватары, свёрнутое меню, мелкие форматы |
| berghaus-wordmark-red / -black / -white | только надпись BERGHAUS |
| icons/berghaus-icon-* | значок на квадратной подложке: favicon, иконка приложения (16–1024 px), favicon.ico |

- **SVG** — для сайта и интерфейса, масштабируется без потерь.
- **PDF и EPS** — для типографии.
- **PNG** — прозрачный фон, ширина от 128 до 4096 px.

## Правила
- **Охранное поле** — не меньше высоты буквы «B» в надписи BERGHAUS со всех сторон. В файлах поле уже заложено: около 6 % высоты.
- **Минимальный размер полного логотипа:** 96 px по ширине на экране, 25 мм в печати. Меньше — используйте знак.
- **Нельзя:** растягивать, менять цвета и порядок элементов, добавлять тени и обводки, ставить цветной вариант на пёстрый фон.
